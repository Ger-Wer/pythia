# Archive

Дата актуализации: 2026-04-28

Этот каталог хранит исторические материалы, которые больше не должны мешать чтению активного репозитория.

## Что здесь лежит

- `root-history/` - старые session logs, deployment reports, research notes и промежуточные отчёты.
- `docs-history/` - устаревшие top-level docs, которые больше не отражают текущую архитектуру или стадию проекта.

## Как этим пользоваться

- Не считайте файлы из `archive/` текущим source of truth.
- Используйте их только для исторического контекста, сравнения прошлых решений или восстановления цепочки изменений.
- За текущим состоянием проекта идите в [README.md](../README.md) и [docs/README.md](../docs/README.md).
