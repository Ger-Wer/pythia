## 📝 Technical Notes

### Why Migration Failed Initially
SQL scripts in `sql/decision_core.sql` use CREATE TABLE statements, which only work for new databases. Existing production databases need ALTER TABLE statements for schema changes.

### Migration Strategy
- `scripts/migrate_db.sh` checks for missing columns before adding them
- Idempotent: safe to run multiple times
- Runs automatically on every container startup
- Logs migration status for monitoring
