# R8: контролируемый запуск бумажного цикла со связчиком — план rollout

Решение от 23 октября 2026. Исполнитель — Muse (архитектор и инженер Pythia).
Этап R8 мастер-карты (v2.18): первое боевое включение paper-цикла пилота
(c21967f) и связчика свидетельств R7 (6ec25e0) в расписание на amper,
затем технический soak — 7 дней измерений.

## Что запускается

- Образ pythia-v2:r8 собирается из ветки codex/evidence-r8-rollout
  (потомок принятого R7). Отличие от боевого main (ee6460f): только paper-цикл,
  связчик, их тесты и две строки расписания/входа. Общие задания
  (snapshot/analyze/healthcheck) не меняются.
- Расписание (UTC): 08:00 snapshot, 08:15 paper-cycle, 08:25 paper-link,
  вс 09:00 analyze, 20:00 healthcheck.
- Включения — только env в боевом .env: PYTHIA_PAPER_ENABLED=1,
  PYTHIA_PAPER_TELEGRAM_ENABLED=1, PYTHIA_PAPER_TELEGRAM_CHAT_ID=<существующий
  канал Pythia>, PYTHIA_PAPER_EVENT_SLUG=fed-decision-in-october-20260617190323537.
- Манифест свидетельств — файл в каталоге данных (не в git):
  python/evaluation/data/evidence_manifest.json, из примера
  docs/examples/evidence_manifest_fomc_2026-10-28.json.
- Состояние пилота: python/evaluation/data/paper (bind-mount, переживает
  пересоздание контейнера).

## Ворота запуска (по порядку, стоп при первом провале)

1. Сьют ветки зелёный в проектном окружении (pytest python/).
2. Preview-прогон нового образа БЕЗ включений и БЕЗ отправки: цикл завершается,
   состояние согласовано (прогноз записан или честный blocked по входам).
3. Первое PAPER-сообщение: ручной paper-cycle с включениями; сверены запись
   прогноза в ledger, outbox forecast:<id> = confirmed с message_id.
4. Повтор: второй ручной запуск не создаёт дублей (already_recorded,
   повторной отправки нет).
5. Связчик: ручной paper-link; цепь первого прогноза записана, digest отчёта
   verify воспроизводим.
6. Учёт: ledger.report() сходится; healthcheck зелёный; контейнер healthy.

## Откат

При провале любого ворота после переключения: вернуть тег образа
pythia-v2:latest и прежние .env/docker-compose.yml (бэкапы рядом), пересоздать
контейнер. Состояние paper/ сохраняется для разбора; посты канала не удаляются
и не повторяются.

## Soak (7 дней, 24–31.10)

Ежедневные факты: запуски цикла и связчика, свежесть входов, пропуски и их
причины, состояния доставки (включая uncertain), расходы (вызовы/токены —
пилот ходит только в публичные источники, LLM-вызовов нет). Заседание ФРС
28.10 и расчёт по нему входят в окно. Разбор soak — 31.10, отдельной записью
приёмки; критерии R8 из карты: первое сообщение/повтор/учёт сверены,
измерены сделанная работа, свежесть, пропуски, восстановление и расходы.

## Не входит в R8

Новая вселенная рынков после октябрьского FOMC (нужно отдельное решение),
замена модели прогноза пилота на R6, реальные деньги.
