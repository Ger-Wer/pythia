# Pythia: бумажная торговля и существующий канал

Решение владельца от 17 октября 2026: строим бумажную торговлю и одновременно
проверяем существующий Telegram-канал. Канал — часть тестируемого продукта.
Реальных ставок, сторонних денег и реферальных ссылок нет.

## Что реализовано

Полный цикл: свежие публичные данные → неизменяемый прогноз → попытка виртуальной
покупки по доступному объёму → публикация PAPER → подтверждённый исход → результат.
Канал и бумажный учёт используют один идентификатор прогноза.

- Начальный виртуальный капитал $1000, попытка входа $10 вместе с комиссией.
- Лимит открытых затрат: 5% капитала на рынок, 10% на событие, 25% суммарно.
- Учитываются предложения продавцов, глубина, комиссия и допустимая цена.
  Нехватка объёма означает пропуск. Размер заявки проверяется в долях.
- Прогноз записывается до получения котировки для исполнения. Фиксируются отдельно
  время наблюдения книги и время последнего изменения книги у поставщика.
- Все прогнозы, виртуальные сделки, пропуски и исходы сохраняются в SQLite.
  Записи учёта нельзя изменять или удалять через приложение.
- Повтор запуска не создаёт вторую сделку или повторную выплату.
- Публикация действует 10 минут для входа. Неподтверждённая отправка не повторяется
  автоматически; оператор сверяет видимый ID и выполняет reconcile.
- Результат — отдельное сообщение в ответ на исходный прогноз. Убытки не фильтруются.
  Непубликовавшиеся прогнозы остаются в общем учёте и требуют внимания оператора.
- Еженедельная сводка содержит закрытые/открытые позиции, реализованный PnL после
  комиссий, Brier модели и рынка, число завершённых независимых событий.
  Несколько ежедневных прогнозов одного события не становятся независимыми исходами.
- Открытые позиции учитываются по затратам. Рыночная оценка и рыночная просадка пока
  не реализованы; `realised_drawdown` отражает только завершённые события.

## Первый эксперимент

Первый источник вероятностей — условная модель `zq-effr-25bp-v1` для ближайшего FOMC.
Она использует дневную EFFR New York Fed и конкретный месячный ZQ Yahoo.
Поддерживается только текущий месяц при постоянной наблюдавшейся EFFR с его начала.
Срок источников — максимум 96 часов для выходных, получение — максимум 60 секунд.
После заявления ФРС в 14:00 New York новый прогноз этого заседания запрещён.

Это гипотеза: средняя ставка фьючерса сама по себе не определяет распределение
вероятностей. Модель допускает сохранение ставки либо один шаг 25 б.п. в сторону
сдвига; встречные сценарии и более крупные изменения не моделируются. Сдвиг больше
25 б.п., нестабильная EFFR, старые или будущие данные блокируют прогноз.
К запасу 3 процентных пункта добавляется чувствительность к половине тика 0,0025
фьючерса после перевода в вероятность. Это резерв чувствительности, не доверительный
интервал. Даже на бумаге сделка не обязательна.

Стартовая вселенная явно разрешена конфигурацией: октябрьский FOMC, один рынок
сохранения ставки. CPI/GDP/AI пока не имеют готовых моделей и не выдаются за работающие.
После октябрьского события потребуется добавить следующую проверенную вселенную;
автоматически подставлять иной рынок под прежнее описание запрещено.

## Запуск и управление

Только сервер amper. Локальное выполнение проекта и тестов запрещено конституцией.

В серверном `.env` нужны явные настройки:

```text
PYTHIA_PAPER_ENABLED=1
PYTHIA_PAPER_TELEGRAM_ENABLED=1
PYTHIA_PAPER_TELEGRAM_CHAT_ID=<существующий канал Pythia>
PYTHIA_PAPER_EVENT_SLUG=fed-decision-in-october-20260617190323537
TELEGRAM_BOT_TOKEN=<уже настроенный бот с правом публикации>
```

Секреты в Git не добавляются. Отправка требует одновременно переменную включения
и явный флаг `--send`. Без настроенного канала предварительный прогон пишет только
в отдельный каталог preview. Рабочие данные: `python/evaluation/data/paper/`.

```bash
# Предварительный прогон без отправки, отдельное состояние.
ssh pythia@amper 'cd /home/pythia/pythia && docker compose run --rm --entrypoint python3 pythia-v2 -m python.evaluation.paper_cycle --state-dir /app/python/evaluation/data/paper-preview --event-slug fed-decision-in-october-20260617190323537'

# Один рабочий цикл по уже включённой серверной конфигурации.
ssh pythia@amper 'cd /home/pythia/pythia && docker compose exec -T pythia-v2 /app/scripts/entrypoint.sh paper-cycle'
```

В расписании: сбор 08:00 UTC, бумажный цикл 08:15 UTC, анализ воскресенье 09:00 UTC,
проверка здоровья 20:00 UTC. Новая ревизия — максимум одна в день; публикуется первый
прогноз, существенное изменение вероятности или выраженное расхождение с рынком.

Если отправка `uncertain`, вручную проверить ID поста и подтвердить доставку:

```python
from python.evaluation.paper_telegram import Outbox
box = Outbox('python/evaluation/data/paper/outbox.sqlite3')
box.reconcile('forecast:1', observed_message_id)
```

Не повторять неопределённые отправки вслепую. Закрытый рынок без однозначного winner
помечается для ручной сверки; extreme price не является исходом. `VOID` в симуляторе
возвращает затраты и комиссию по явному допущению; `SPLIT` выплачивает 0,50 за долю.
Автоматически эти случаи не угадываются.

## Критерии следующего решения

Технический тест: живой сбор, отсутствие задним числом созданных прогнозов,
корректные комиссии и лимиты, отсутствие дублей после рестарта, доставка проигрышей,
счётчики сделанной работы и явный отказ при плохих данных.

Исследовательский тест: достаточно независимых завершённых событий; сравнение
модели с рыночной вероятностью, PnL после расходов и устойчивость на новых событиях.
Один FOMC даже с десятками снимков не доказывает доходность. Исторический бэктест
остаётся открытой задачей. Деньги и рекламное масштабирование требуют отдельного
решения после результатов; сейчас это работающий эксперимент, не доказанный заработок.
